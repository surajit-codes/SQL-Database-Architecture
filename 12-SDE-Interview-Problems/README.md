# TechBazar SDE Interview Problems

## Problems Solved (Day 12)
* **High-Value Category Revenue:** Combined `INNER JOIN`, cross-table multiplication, `GROUP BY`, and `HAVING` to generate a filtered revenue report.
* **The Runner-Up (2nd Highest Value):** Solved the classic "Nth highest" interview question using nested subqueries and the `MAX()` function to dynamically find the second most expensive product, gracefully handling ties.

## Key Takeaway
Solving these problems independently proved that I can now combine multiple SQL concepts (Joins, Aggregations, Subqueries, Filtering) to solve complex, real-world business scenarios. The nested subquery approach for finding the 2nd highest value is an elegant solution that works flawlessly even if multiple products share that same second-highest price.
