# TechBazar Daily Sales Report

## Concepts Learned (Day 7)
* **INNER JOIN:** Learned how to query data from two different tables simultaneously by linking them through their Primary and Foreign Keys.
* **Table Aliases:** Used shorthand names for tables (like `p` for products, `s` for sales) to write cleaner, more professional code.
* **Cross-Table Math:** Calculated dynamic values (like total bill) by multiplying columns from two completely separate tables in the same `SELECT` statement.

## Key Takeaway
`INNER JOIN` only brings back rows where there is a match in BOTH tables. It's incredibly powerful because it allows us to store data efficiently (Normalization) without losing the ability to generate comprehensive, human-readable reports on the fly. Using aliases is a game-changer for writing complex queries quickly.
